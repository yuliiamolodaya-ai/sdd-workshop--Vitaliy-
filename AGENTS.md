# AGENTS.md

Навчальна копія публічного сайту Фундації Лятошинського (`lf-client`): Next.js-застосунок про спадщину Бориса Лятошинського, діяльність фундації, архів, новини, співпрацю та підтримку. Призначений для курсу spec-driven BA workshop. Зовнішня MongoDB не потрібна: під час запуску створюється in-memory база з демо-даними.

## Основні сторінки

Маршрути живуть у `app/[lang]/`. Мови: `uk` (основна) та `en`.

| Маршрут | Бізнес-призначення |
| --- | --- |
| `/` | Головна: вхід до спадщини композитора і діяльності фундації |
| `/about-us` | Про фундацію: місія та цілі |
| `/biography` | Життєпис Бориса Лятошинського |
| `/artistry` | Творчість: музичні твори |
| `/research` | Дослідження та наукові роботи |
| `/news` | Новини, події та згадки в медіа |
| `/archive` | Архів: фонди документів, листів, афіш, рукописів |
| `/archive/[fund]` | Окремий фонд архіву |
| `/archive/[fund]/[case]` | Справа фонду та її документи |
| `/cooperation` | Співпраця для партнерів, благодійників і меценатів |
| `/support-us` | Підтримка фундації: разовий внесок або підписка |
| `/contacts` | Запит через контактну форму |
| `/war-in-ukraine` | Робота фундації під час війни в Україні |
| `/privacy-policy` | Політика конфіденційності та обробка персональних даних |
| `/terms` | Умови користування сайтом |

## Конвенції

- Код пишеться на TypeScript.
- Новий код експортує іменовані символи. `export default` лишається лише там, де його вимагає Next.js: `page`, `layout`, `middleware`, `route`, конфіги фреймворку.
- Українська (`uk`) — основна мова інтерфейсу і текстів у `i18n/messages/uk.json`. Англійська (`en`) — друга локаль.

## Навчальний репозиторій

Це демо для воркшопу, не прод. In-memory MongoDB створюється на старті, наповнюється демо-даними і скидається після зупинки застосунку. Зміни в даних між запусками не зберігаються.
