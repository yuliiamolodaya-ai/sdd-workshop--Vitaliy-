## 1. Гіпотеза

**Ми вважаємо, що** обов’язкова валідація телефону в UI форми достатня, щоб відвідувач **не надіслав** звернення без номера.  
**Для** відвідувача публічної сторінки контактів (**IN-05** частково — лише контакти, **en** у PoC).  
**Досягне** помилки біля поля телефону без мережевого submit.  
**Ми зрозуміємо, що маємо рацію, коли** порожній телефон **блокує** відправку і з’являється текст помилки (**SIG-P-01**); **спростуємо**, якщо submit проходить без номера або запит іде в мережу.

| ID | Елемент гіпотези | Перевірюваний? | Лейбл | Батьківський ID |
|----|------------------|----------------|-------|-----------------|
| H-01 | Якщо телефон зробити обов’язковим у формі, відвідувач **не відправить** звернення з **порожнім** телефоном і **побачить** помилку біля поля (клієнт). | **Так** | Grounded | **RULE-06**, **IN-02**, issue #2 реч. 2; `poc-summary` §1 Проба 1; §10 spec |

**Одне речення для стейкхолдера:** «Без номера телефону форма на контактах не відправляє звернення і показує помилку біля поля» (ен-копія зафіксована в Day 3; **uk** — **Q-05**).

## 3. Намір: MVP чи PoC

| Вимір | PoC (навчитися) | MVP (мінімальна цінність) |
|-------|-----------------|---------------------------|
| Основна мета | Перевірити припущення | Випустити корисну цінність |
| Аудиторія | Внутрішня + дружні пілоти | Реальні користувачі |
| Планка якості | Достатньо, щоб побачити сигнал | Достатньо, щоб підтримувати й вимірювати |
| Успіх | Дізналися / зупинили / змінили курс | Утримання / конверсія / експлуатація |

**Ця ініціатива:** ☑ **PoC** ☐ MVP ☐ Гібрид

**PoC** — бо зріз відповідає на **одне** питання (клієнтська блокада без телефону), а не на повну поставку **FEAT-CONTACT-002** (**RULE-16**, **RULE-17**, **OUT-05**). Лейбл: **Grounded** (`mvp-poc-slice-template.md` §3; §10 spec «одне питання»).

Замовник уже просить обов’язковий телефон у **issue #2** (**RULE-06**, **IN-02**), але Day 3 довів лише **частину** шляху (**en**, форма); повний реліз вимагає **AC-01**, **AC-11**, **Q-05**, **Q-11** — це **наступні** зрізи, не цей PoC. Лейбл: **Grounded** (`poc-summary` §5–6).
